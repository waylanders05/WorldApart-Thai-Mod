มอดภาษาไทย World Apart (不问凡尘) - เวอร์ชัน v0.2 (ทดสอบ)
=====================================================================

มอดนี้เปลี่ยนข้อความในเกมทั้งหมดเป็นภาษาไทย
(เมนู, ไอเทม, สกิล, เควสต์, บทสนทนา) และเพิ่มฟอนต์ภาษาไทย
เสียงพากย์ยังเป็นภาษาจีนตามต้นฉบับ

** นี่คือเวอร์ชันทดสอบ แปลด้วย AI (Claude) แล้วตรวจด้วยระบบอัตโนมัติ
   อาจมีคำแปลแปลก ๆ หรือข้อความล้นกรอบบ้าง ช่วยแจ้งด้วยนะครับ **

ดาวน์โหลดเวอร์ชันล่าสุด / แจ้งปัญหา:
https://github.com/waylanders05/WorldApart-Thai-Mod


รองรับเกมเวอร์ชันไหน
--------------------
- 不问凡尘 / World Apart บน Steam
- ทำจาก build 26646193 (ถ้าเกมอัปเดตหลังจากนี้ ตัวติดตั้งจะแจ้งเตือนและไม่แก้ไฟล์ใด ๆ
  ต้องรอมอดเวอร์ชันใหม่)


วิธีติดตั้ง
-----------
1. ปิดเกมก่อน
2. แตกไฟล์ zip นี้ไว้ที่ไหนก็ได้ (เช่น Desktop)
3. ดับเบิลคลิก  install.bat
   - ตัวติดตั้งจะหาโฟลเดอร์เกมใน Steam ให้อัตโนมัติ
   - ถ้าหาไม่เจอ จะให้วางที่อยู่โฟลเดอร์เกม
     (Steam > คลิกขวาที่เกม > Manage > Browse local files)
   - ถ้า Windows เตือนเรื่องความปลอดภัย ให้กด "More info" > "Run anyway"
4. เปิดเกม ไปที่ ตั้งค่า (Settings) > ภาษา (Language)
   แล้วเลือก "ภาษาไทย" (มอดใช้ช่องของภาษาอังกฤษ)
   ถ้าเกมเป็นภาษาอังกฤษอยู่แล้ว จะเป็นภาษาไทยทันที

ตัวติดตั้งจะสำรองไฟล์เดิมไว้ที่โฟลเดอร์เกม\ThaiMod_backup ก่อนแก้ไขเสมอ
ถ้าเคยติดตั้งมอดเวอร์ชันก่อนหน้าไว้ รัน install.bat ของเวอร์ชันนี้ได้เลย จะอัปเดตให้เอง


มอดนี้ทำงานอย่างไร
------------------
ในไฟล์ zip ไม่มีไฟล์ของเกม มีแค่ "patch" (ส่วนที่เปลี่ยน: ข้อความไทยและตัวอักษรไทย)
ตัวติดตั้งจะอ่านไฟล์เกมในเครื่องคุณ แล้วสร้างไฟล์ภาษาไทยขึ้นมาใหม่
- ใช้ PowerShell ที่มีใน Windows อยู่แล้ว ไม่ต้องลงโปรแกรมเพิ่ม
- โค้ดที่ใช้ประกอบไฟล์อยู่ใน tools\ThaiModPatcher.cs เปิดอ่านได้
- ตรวจไฟล์ทุกไฟล์ด้วย SHA-256 ก่อนและหลังแก้ ถ้าไม่ตรงจะไม่แตะไฟล์เกม


วิธีถอนการติดตั้ง
-----------------
- ดับเบิลคลิก  uninstall.bat  (คืนไฟล์เดิมจากที่สำรองไว้)
- หรือใน Steam: คลิกขวาที่เกม > Properties > Installed Files >
  Verify integrity of game files


เมื่อเกมอัปเดต
--------------
Steam อาจเขียนไฟล์ใหม่ทับมอด (ข้อความกลับเป็นภาษาอังกฤษ)
ให้ลองรัน install.bat อีกครั้ง ถ้าขึ้นว่า "ไฟล์เกมไม่ตรงกับเวอร์ชัน"
แปลว่าต้องรอมอดเวอร์ชันใหม่


ที่รู้อยู่แล้วว่ายังไม่สมบูรณ์
---------------------------
- เสียงพากย์ยังเป็นภาษาจีน
- แชทคุยกับ NPC แบบ AI (พิมพ์คุยอิสระ) คำตอบมาจากเซิร์ฟเวอร์ของเกม อาจยังเป็นภาษาอังกฤษ
- บางหน้าจออาจมีข้อความล้นกรอบ หรือตัวอักษรเป็นกรอบสี่เหลี่ยม □
- ชื่อเฉพาะบางชื่ออาจยังสะกดไม่ตรงกันทุกที่


แจ้งปัญหา
---------
ถ่ายรูปหน้าจอที่มีปัญหา แล้วบอกว่าอยู่ตรงไหนของเกม (เมนูไหน / ฉากไหน)
แจ้งได้ที่ Issues ของหน้า GitHub ด้านบน หรือส่งให้คนที่แจกมอดนี้ให้คุณ

- ต้องมีเกมนี้ใน Steam จึงจะใช้ได้ (มอดสร้างไฟล์จากเกมในเครื่องคุณ)

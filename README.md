# มอดภาษาไทย World Apart (不问凡尘)

มอดแปลไทยโดยแฟนเกม (ไม่เป็นทางการ) สำหรับเกม **World Apart / 不问凡尘** บน Steam

- แปลข้อความทั้งเกมเป็นภาษาไทย ได้แก่ เมนู ไอเทม สกิล เควสต์ และบทสนทนา (ประมาณ 45,000 ข้อความ)
- เพิ่มฟอนต์ภาษาไทย (Sriracha) และจัดตำแหน่งสระกับวรรณยุกต์ไม่ให้ซ้อนกัน
- เสียงพากย์ยังเป็นภาษาจีนตามต้นฉบับ

> **เวอร์ชันทดสอบ:** แปลด้วย AI (Claude) และตรวจด้วยระบบอัตโนมัติ อาจมีคำแปลแปลก ๆ หรือข้อความล้นกรอบ
> เจอจุดไหนแปลก ช่วยแจ้งที่ [Issues](https://github.com/waylanders05/WorldApart-Thai-Mod/issues) พร้อมรูปหน้าจอได้เลย

## ดาวน์โหลด

ไปที่ [**Releases**](https://github.com/waylanders05/WorldApart-Thai-Mod/releases/latest)
แล้วโหลดไฟล์ `WorldApart_ThaiMod_<เวอร์ชัน>.zip` (ประมาณ 6 MB)

## วิธีติดตั้ง

1. ปิดเกม
2. แตกไฟล์ zip ไว้ที่ไหนก็ได้ เช่น Desktop
3. ดับเบิลคลิก `install.bat`
   - ตัวติดตั้งจะหาโฟลเดอร์เกมใน Steam ให้เอง ถ้าหาไม่เจอจะให้วางที่อยู่โฟลเดอร์เกม
     (Steam > คลิกขวาที่เกม > Manage > Browse local files)
   - ถ้า Windows เตือนเรื่องความปลอดภัย ให้กด **More info > Run anyway**
   - ใช้เวลาประมาณ 1-3 นาที เพราะต้องสร้างวิดีโอบทกลอนเปิดเรื่องที่มีกลอนภาษาไทย
4. เปิดเกม ไปที่ **ตั้งค่า (Settings) > ภาษา (Language)** แล้วเลือก **"ภาษาไทย"** (มอดใช้ช่องของภาษาอังกฤษ)

ถ้าเคยติดตั้งเวอร์ชันก่อนหน้าไว้ รัน `install.bat` ของเวอร์ชันใหม่ได้เลย ตัวติดตั้งจะอัปเดตให้

## วิธีถอนการติดตั้ง

- ดับเบิลคลิก `uninstall.bat` เพื่อคืนไฟล์เดิมจากที่สำรองไว้
- หรือใน Steam: คลิกขวาที่เกม > Properties > Installed Files > **Verify integrity of game files**

## รองรับเกมเวอร์ชันไหน

ทำจาก Steam build **26646193** ถ้าเกมอัปเดตแล้วไฟล์เปลี่ยน ตัวติดตั้งจะแจ้งเตือนและไม่แตะไฟล์เกม
ให้รอมอดเวอร์ชันใหม่

## มอดนี้ทำงานอย่างไร

ในมอด**ไม่มีไฟล์ของเกม** มีแค่ patch (`patches/*.wtp`) ที่เก็บเฉพาะส่วนที่เปลี่ยน คือข้อความไทยและตัวอักษรไทย
ตัวติดตั้ง (`tools/install.ps1` กับ `tools/ThaiModPatcher.cs`) ทำงานแบบนี้:

1. ตรวจไฟล์เกมด้วย SHA-256 ว่าตรงกับเวอร์ชันที่รองรับ ถ้าไม่ตรงจะหยุดทันที
2. สำรองไฟล์เดิมไว้ที่ `<โฟลเดอร์เกม>\ThaiMod_backup`
3. สร้างไฟล์ภาษาไทยจากไฟล์เกมในเครื่องคุณกับ patch แล้วตรวจ SHA-256 อีกครั้งก่อนแทนที่ไฟล์เดิม
   ถ้ามีขั้นไหนพลาด จะคืนไฟล์เดิมให้
4. วิดีโอบทกลอนเปิดเรื่องมีตัวหนังสือจีนฝังอยู่ในภาพ ตัวติดตั้งจึงใช้ ffmpeg ที่มากับเกม
   เข้ารหัสวิดีโอใหม่โดยใส่กลอนภาษาไทย (`video/poem_2010100.ass`) แทน

ใช้แค่ PowerShell ที่มากับ Windows ไม่ต้องลงโปรแกรมเพิ่ม และโค้ดทั้งหมดเปิดอ่านได้ใน repo นี้

## ที่รู้อยู่แล้วว่ายังไม่สมบูรณ์

- เสียงพากย์ยังเป็นภาษาจีน
- แชทคุยกับ NPC แบบ AI (พิมพ์คุยอิสระ) คำตอบมาจากเซิร์ฟเวอร์ของเกม จึงอาจยังเป็นภาษาอังกฤษ
- บางหน้าจออาจมีข้อความล้นกรอบ หรือตัวอักษรเป็นกรอบสี่เหลี่ยม □
- ชื่อเฉพาะบางชื่ออาจยังสะกดไม่ตรงกันทุกที่
